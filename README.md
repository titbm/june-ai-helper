# JuneAI Helper

Расширение для Chrome, которое генерирует вопросы через AI и автоматически отправляет их в June AI.

## Функционал

- **Генерация вопросов через AI** - 10 естественных вопросов на случайную тему
- **200+ тем** - крипто, блокчейн, ИИ, политика, культура, технологии, наука и т.д.
- **Переключение языка** - кнопка RU/EN для выбора языка генерации
- **Автоматический перевод темы** - при смене языка тема переводится и вопросы перегенерируются
- **Естественный ввод** - печатает посимвольно с задержками, как человек
- **Автоматическая отправка** - все 10 вопросов одним кликом
- **Умные вопросы** - разнообразные типы вопросов (что, как, почему, стоит ли и т.д.)
- **Человеческий стиль** - опечатки, разный регистр, разговорный язык
- **Копирование** - клик на вопрос копирует его в буфер
- **Отдельная отправка** - кнопка "June" для каждого вопроса
- **Остановка** - можно прервать отправку в любой момент
- **Блокировка темы** - замок фиксирует тему для всех генераций

## Установка

1. Скачай репозиторий
2. Открой `chrome://extensions`
3. Включи "Developer mode"
4. "Load unpacked" → выбери папку расширения

## Использование

1. Открой [June AI](https://askjune.ai/app/chat)
2. Кликни иконку расширения
3. Выбери язык (RU/EN) - при смене языка тема автоматически переводится
4. "Обновить запросы" → генерирует новые вопросы
5. Кликни замок чтобы зафиксировать тему (опционально)
6. "Отправить все запросы" → автоматическая отправка

Расширение создаст новый чат и отправит все вопросы с задержками 6-10 секунд между ними.
